# Morrow Café

A responsive two-page website for a neighborhood café, built with HTML, CSS and JavaScript.

**Live site:** https://YOUR-USERNAME.github.io/morrow-cafe/

## Project overview

Morrow Café is a simple website for a local café. The home page shares the café's story, address and opening hours. The menu page lists favorite items, and visitors can save the ones they like.

**Purpose:** give a small café a clean, welcoming online presence.

**Target audience:** students, local workers, families and anyone who enjoys coffee in a relaxed space.

## Features

- Two pages: Home and Menu, linked by a navigation bar
- Responsive layout for desktop and mobile screens
- Mobile navigation menu that opens and closes with a button
- Menu cards generated from a JavaScript list, so items are easy to edit
- "Save" buttons that toggle between Save and Saved, with a live counter
- Saved items are remembered after refreshing the page (browser localStorage)
- Clean design with custom colors and Google Fonts

## Technology stack

- HTML5
- CSS3 (Flexbox, Grid, media queries, CSS variables)
- JavaScript (DOM manipulation, event listeners, localStorage)
- Google Fonts (DM Sans, Playfair Display)
- Hosted on GitHub Pages

## Setup instructions

1. Download or clone this repository.
2. Keep all files in the same folder.
3. Double-click `index.html` to open the site in your browser.

No installation or build step is needed.
